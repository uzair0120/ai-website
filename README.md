# AI-Powered Secure Document Search Portal

Companies have thousands of private files and documents. This project builds a safe internal platform where employees can upload these documents and use AI to search or ask questions about them instantly, without risking data leaks.

## Teams Collaboration
- **Web Dev Team:** Builds the user interface, login screen, document upload portal, and interactive chat box[cite: 2].
- **Python Team:** Builds the backend system, core scripts, and manages database integrations[cite: 2].
- **AI Team:** Builds the RAG (Retrieval-Augmented Generation) search engine so the AI reads uploaded documents and provides exact answers[cite: 2].
- **Cyber Security Team:** Implements security, role-based permissions, and data encryption[cite: 2].
